Nigerian Fashion Marketplace
UI Sitemap + Project Documentation

1. Project Overview
A modern multi-vendor fashion marketplace tailored for Nigeria, enabling buyers and sellers to interact seamlessly.
Key Features: - Multi-vendor system - Nigerian fashion categories (corporate, casual, native) - Real-time chat (buyer-seller + AI chatbot) - Payment integration (Paystack/Flutterwave) - Order tracking (real-time updates) - WhatsApp & call-based customer support (NO email)

4. Tech Architecture
Frontend: - Next.js (App Router) - Tailwind CSS
Backend: - Node.js + Express
Database: - Supabase (PostgreSQL + Realtime)
Payments: - Paystack / Flutterwave
Support: - WhatsApp integration - Call button - AI chatbot

5. Database Overview
Users - id - name - email - role
Products - id - title - price - category - seller_id
Orders - id - user_id - status
Messages - id - sender_id - receiver_id - message
Reviews - id - rating - comment
